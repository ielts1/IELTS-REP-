2. এই পুরো ফোল্ডার (ielts-rep-simple) ZIP করে নিন
3. ZIP ফাইলটা Netlify Drop পেজে টেনে এনে ছাড়ুন বা আপলোড করুন
4. কিছুক্ষণ পর একটা লিংক পাবেন (যেমন: https://something.netlify.app)
5. সেই লিংক শেয়ার করুন — ওয়েবসাইট লাইভ!
